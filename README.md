# 🎯 Number Guess Game

A simple and fun Number Guessing Game built using HTML, CSS, and JavaScript. The player has to guess the correct number within a limited number of attempts.

---

## 🚀 Features

* 🎲 Random number generation
* 🔢 User input for guessing
* 📉 Limited attempts
* 📢 Feedback (Too High / Too Low)
* 🏆 Win/Lose result display
* 🔄 Restart game option

---

## 🛠️ Tech Stack

* HTML
* CSS
* JavaScript

---

## 🎮 How to Play

1. Enter a number in the input field
2. Click on **Submit Guess**
3. Get feedback:

   * If your guess is too high → Try a smaller number
   * If your guess is too low → Try a larger number
4. Continue until you guess correctly or run out of attempts
